Roles y permisos

Cada usuario tiene un solo rol, y sus permisos son los de ese rol. Los roles del sistema vienen del documento del programa y no se eliminan; puede crear roles propios y elegir qué puede hacer cada uno. Si cambia los permisos de un rol, el cambio rige de inmediato para quienes lo tienen.
