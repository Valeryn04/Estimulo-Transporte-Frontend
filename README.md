# Estímulo Social de Transporte · Frontend

Portal ciudadano y portal interno del Estímulo Social de Transporte de la Alcaldía de Barranquilla.
Angular 22 y TypeScript.

```bash
npm install
npm start          # http://localhost:4300 (con la API en :3100)
npm run start:red  # igual, abierto a la red (para probar desde el celular)
npm run build      # compilación de producción en dist/
```

Pruebas: `npm run test:ci`. Lint: `npm run lint`.
